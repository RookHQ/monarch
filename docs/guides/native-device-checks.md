# Device checks for Android and iOS

Behaviours that no host test, simulator test or Robolectric test can prove: they need a physical device with VoiceOver or TalkBack. Everything else is tested in the repository ([accessibility and testing](native-accessibility-and-testing.md)). These are the checks to run on a device before a component is called verified for assistive technology; a result is recorded per item, and a failure becomes an issue.

Until they have been run, nothing in the docs claims that VoiceOver or TalkBack output was checked on a device.

**iOS setup, every item:** a physical iPhone (the oldest supported iOS and the latest), VoiceOver on (Settings > Accessibility > VoiceOver), and the catalogue app `MonarchCatalogue` from `platforms/ios/Sample`. Also run Larger Text at the largest accessibility size, and Increase Contrast, once per item.

**Android setup, every item:** a physical phone (a low-end API 24 class device and the latest), TalkBack on, and the sample app from `platforms/android/sample`. Also run font scale 2.0 and right to left (Developer options, Force RTL) once per item.
