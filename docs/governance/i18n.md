# Internationalisation and right-to-left

What Monarch does for apps in other languages and in right-to-left scripts,
and what it leaves to the app.

## Text

- Components that show text of their own (button labels, empty states,
  screen-reader text such as "Assistant said:") take a `messages` prop. You
  pass only the strings you want to change; the rest keep their defaults.
- The defaults are English. Each such component exports them as
  a constant, for example `PASSWORD_STRENGTH_METER_MESSAGES`; there are 162
  of these constants. Some messages are functions, so you control word order
  and plurals: ``strength: (level) => `Password strength: ${level}` ``.
- Monarch ships no translations and no translation runtime. Use your own
  i18n library and pass its output into `messages` and the text props.

## Numbers, dates and times

- Components that format numbers, money, dates or times use the browser's
  `Intl` APIs and take a `locale` prop (a BCP 47 tag such as `de-DE`).
  Without it most use the runtime locale; read each component's props for
  its default.
- Pass `locale` (and a time zone where the component takes one) when you
  render on the server, so the server and browser output match. The docs
  site's accessibility suite runs in German in the `Pacific/Kiritimati` time
  zone to catch examples that do not.

## Right-to-left

- Set `dir="rtl"` on `<html>` (or on a wrapping element). Monarch has no
  global switch of its own.
- Layout uses CSS logical properties (`padding-inline`, `margin-inline`,
  `inset-inline`, `inset-block`), so spacing and positions follow the
  direction. Icons that point a way (chevrons, arrows) and directional motion
  are mirrored with `:dir(rtl)` in 40 stylesheets.
- Components with arrow-key navigation (tabs, segmented controls, toggle
  groups, sliders, calendars, tree views and others) read the direction from
  the nearest `dir` attribute, then the computed `direction`, so Left and
  Right follow the reading direction. Several also take a `dir` prop.
- Right-to-left behaviour is covered by tests in 18 component test files.

## Known limits

- There is no exported direction provider. Radix-based components that do
  not read the direction themselves, such as `DropdownMenu`, keep
  left-to-right arrow-key rules for submenus.
- Some stylesheets still use physical `left` or `right` (15 of 514). Many
  centre an element (`left: 50%`) or follow a physical `side` prop
  (`Sheet side="right"`), but not all: the `Dialog` close button, for
  example, stays at the top right in right-to-left pages.
- Visual baselines are taken in left-to-right only.
- Right-to-left support needs `:dir()`, which sets the browser minimums in
  [browser support](browser-support.md).
- Monarch does not choose fonts per script. If the default type stack
  (`--mn-font-sans`) does not cover a script you need, set your own.

To report a problem, see the [accessibility statement](accessibility-statement.md#report-a-problem).
