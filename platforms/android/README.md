# Monarch for Android

The Android implementation of the Monarch design system, written in Kotlin
with Jetpack Compose on top of Material 3.

Monarch for Android looks like Monarch and behaves like Android
([the rule](../../docs/guides/native-look-and-feel.md)). It is not a port of
the React components: it shares the tokens, the role names, the component
vocabulary and the accessibility rules with the web and iOS implementations.
Fields, buttons, selection controls, tabs, chips, badges, cards, banners,
progress indicators and list rows are drawn by Monarch from Compose foundation;
dialogs, sheets, menus and pickers are the platform's, themed with Monarch's
shape, colour and type. The architecture is described in
[docs/architecture/NATIVE-PLATFORMS.md](../../docs/architecture/NATIVE-PLATFORMS.md).

Status: unreleased. The version is the `@rookcom/monarch-react` version, in
the `0.14.x` patch series; the first native release ships with the next
patch. Nothing is published to Maven Central yet. No Rook product ships on it
yet, so the API has not been proven in production and may change.

## Modules

| Module                  | Artifact                              | Contents                                                                                       |
| ----------------------- | ------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `monarch-tokens`        | `dev.monarchui:monarch-tokens`        | Generated token constants. Pure Kotlin, no Android, no Compose.                                |
| `monarch-compose`       | `dev.monarchui:monarch-compose`       | Theme, foundations, accessibility helpers and components.                                      |
| `monarch-fonts-poppins` | `dev.monarchui:monarch-fonts-poppins` | Optional Poppins typeface (SIL Open Font License 1.1).                                         |
| `monarch-sample-icons`  | not published                         | Outlined Material icons for the sample app, previews and tests only. No library depends on it. |
| `sample`                | not published                         | Catalogue app that shows every component in all four themes.                                   |
| `build-logic`           | not published                         | Convention plugins shared by the modules.                                                      |

`inventory/<id>.json` documents one entry of the web catalogue each: the
component or the plain Material 3 API that covers it, its API, options,
states, accessibility behaviour and compiled examples. The documentation site
reads those files. `components.json` is a roll-up generated from them; never
edit it by hand.

App developers: see [docs/USING-MONARCH.md](docs/USING-MONARCH.md).
To add a component, follow [docs/ADDING-COMPONENTS.md](docs/ADDING-COMPONENTS.md).
Adding a component only adds files; every shared list is generated.

## Layout

```text
inventory/<id>.json                      one documentation file per web component id
inventory/schema.json                    the schema, shared with iOS
components.json                          generated from inventory/
monarch-compose/src/main/kotlin/dev/monarchui/
  theme/ foundation/ accessibility/      the theme, type, spacing, shape, elevation, motion, icon, helpers
  internal/                              shared building blocks for components (not public API)
  components/<family>/<name>/            one folder per component, one public component per file
monarch-compose/src/main/res/values/strings_<name>.xml   built-in strings, one file per component
monarch-compose/src/debug/kotlin/...     @Preview functions (not published)
monarch-compose/src/test/kotlin/.../components/<family>/<Name>Test.kt   tests and fixtures
sample/src/main/kotlin/.../sections/<family>/<Name>Section.kt           catalogue pages
```

Generated by Gradle into `build/`, never into the source tree: the compiled
examples of every inventory file, the registry of test fixtures, and the
navigation of the catalogue.

## Requirements

To build this repository:

- JDK 21. The build declares a JDK 21 toolchain and does not download one.
- Android SDK with platform `android-37.0` and build-tools 36.0.0. Set
  `ANDROID_HOME`, or `sdk.dir` in `local.properties`.
- Network access on the first build: Gradle downloads its distribution and
  the dependencies, and Robolectric downloads the Android runtime it runs
  the tests on.
- No other tool. The generated token file is committed, so Node is not
  needed.

To use the library in an app:

- `minSdk` 24 or later, `compileSdk` 37 or later.
- Jetpack Compose with Material 3. The library is built against the Compose
  BOM in `gradle/libs.versions.toml` and exposes Compose UI, Foundation and
  Material 3 as API dependencies.
- Java 17 bytecode.

## Install from source

Monarch for Android is not on Maven Central yet. From the first release, the
coordinates are `dev.monarchui:monarch-compose` and
`dev.monarchui:monarch-tokens`, at the same version as
`@rookcom/monarch-react` (for example `0.14.6`), resolved from
`mavenCentral()`. Until then, publish to a local Maven repository and add
that repository to the app.

```sh
cd platforms/android
./gradlew publishAllPublicationsToLocalRepository
```

This writes `dev.monarchui:monarch-tokens` and
`dev.monarchui:monarch-compose`, at the version in
`gradle/libs.versions.toml`, to `platforms/android/build/repo`.
In the app, in `settings.gradle.kts`:

```kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("/path/to/monarch/platforms/android/build/repo") }
    }
}
```

and in the module's `build.gradle.kts`:

```kts
dependencies {
    implementation("dev.monarchui:monarch-compose:<version>")
}
```

`monarch-compose` brings `monarch-tokens` with it.

## Getting started

Wrap the content of the activity in `MonarchTheme`. Everything inside,
Monarch components and plain Material 3 components alike, is themed.

```kotlin
class InvoicesActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            MonarchTheme {
                InvoicesScreen(onCreate = { })
            }
        }
    }
}

@Composable
fun InvoicesScreen(onCreate: () -> Unit) {
    Scaffold { innerPadding ->
        Column(
            modifier = Modifier
                .padding(innerPadding)
                .padding(MonarchTheme.spacing.space4),
        ) {
            MonarchText(text = "Invoices", style = MonarchTextStyle.Title)
            MonarchText(text = "3 are due this week.", color = MonarchTheme.colors.textMuted)
            MonarchButton(text = "New invoice", onClick = onCreate, variant = MonarchButtonVariant.Primary)
        }
    }
}
```

## Theme setup

Appearance has three independent inputs. Each has a default, so
`MonarchTheme { }` alone follows the system.

| Input      | Type              | Values                         | Default                                                      |
| ---------- | ----------------- | ------------------------------ | ------------------------------------------------------------ |
| `scheme`   | `MonarchScheme`   | `System`, `Light`, `Dark`      | `System`: the system dark theme setting                      |
| `contrast` | `MonarchContrast` | `System`, `Standard`, `More`   | `System`: the system contrast setting (Android 14 and later) |
| `accent`   | `MonarchAccent`   | one of `MonarchTokens.Accents` | `MonarchTokens.Accents.rook`                                 |

`resolveMonarchTheme` turns the three inputs into one of the four themes
(`light`, `dark`, `hc-light`, `hc-dark`). It is a pure function, so the rule
can be tested without a device.

```kotlin
@Composable
fun AtlasTheme(content: @Composable () -> Unit) {
    MonarchTheme(
        scheme = MonarchScheme.System,
        contrast = MonarchContrast.System,
        accent = MonarchTokens.Accents.atlas,
        typography = monarchTypography(fontFamily = FontFamily.SansSerif),
        dynamicColor = false,
        content = content,
    )
}
```

- `typography`: Monarch uses the system typeface with Monarch's sizes,
  weights and tracking. Pass `monarchTypography(fontFamily = ...)` to use a
  product typeface. No font is bundled.
- `dynamicColor`: off by default, because the accent is part of the brand.
  When `true` on Android 12 or later, plain Material 3 components take the
  wallpaper-based colour scheme. Monarch components keep Monarch colours.

To pin one theme, for example in a preview or a screenshot, pass the tokens:

```kotlin
@Composable
fun DarkAtlasPreview(content: @Composable () -> Unit) {
    MonarchTheme(tokens = MonarchTokens.dark.withAccent(MonarchTokens.Accents.atlas), content = content)
}
```

Inside the theme, read values through the `MonarchTheme` object:
`MonarchTheme.colors`, `.typography`, `.shapes`, `.spacing`, `.elevation`,
`.motion`, `.isDark`, `.isHighContrast` and `.focusRingWidth`.

### How Monarch maps to Material 3

`MonarchTheme` wraps `MaterialTheme` with a colour scheme, typography and
shapes derived from the Monarch values in one place
(`theme/MaterialMapping.kt`). Material's `primary` and `error` map to the
`accentStrong` and `dangerStrong` roles, because Material uses them both as
fills and as text on a surface. `MonarchButton` fills with `accentSolid`.

## Tokens

`monarch-tokens` holds the generated constants: primitives, the four themes
with 96 colour roles each, five shadow levels, and 21 accents. The file
`MonarchTokens.kt` is written by `packages/tokens/scripts/emit-native.ts`; do
not edit it. Colours are ARGB `Long` values, lengths are dp, type sizes are
sp, durations are milliseconds.

```kotlin
val canvasArgb: Long = MonarchTokens.light.colors.bgCanvas
val gutter = MonarchTokens.Space.space4.dp
val bodySize = MonarchTokens.FontSize.base.sp
val highContrastDark = MonarchTokens.hcDark.withAccent(MonarchTokens.Accents.atlas)
```

In Compose code, prefer `MonarchTheme.colors` and `MonarchTheme.spacing` to
the raw tokens: they are already `Color` and `Dp`, and the colours follow the
active theme.

## Components

| Component                                                   | What it is                                                                                              |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `MonarchText`                                               | Text in one of nine type roles, over Material 3 `Text`.                                                 |
| `MonarchButton`                                             | Variants primary, secondary, ghost, danger; sizes sm, md, lg; loading; icons. Over Material 3 `Button`. |
| `MonarchTextField`                                          | Label, helper text and error message, over `OutlinedTextField`.                                         |
| `MonarchCheckboxRow`, `MonarchSwitchRow`, `MonarchRadioRow` | A Material 3 control with a label, as one row that toggles as a whole.                                  |
| `MonarchCard`                                               | A bordered surface, optionally elevated or tappable, over `Surface`.                                    |
| `MonarchDivider`                                            | A 1dp line, over `HorizontalDivider` and `VerticalDivider`.                                             |
| `MonarchProgress`                                           | Linear or circular, determinate or indeterminate.                                                       |
| `MonarchIcon`                                               | An icon at a Monarch size. No icon set is bundled.                                                      |
| `MonarchBadge`                                              | A status label: tones neutral, info, success, warning, danger; variants subtle, solid, outline.         |
| `MonarchBanner`                                             | An inline status message with a tone, title, message, icon and action.                                  |

The bare checkbox, switch and radio button, and navigation, dialogs, sheets,
menus, tabs, lists and date pickers are the Material 3 components, used
directly inside `MonarchTheme`.

Packages follow the families of the web catalogue, for example
`dev.monarchui.components.actions.button.MonarchButton` and
`dev.monarchui.components.datadisplay.badge.MonarchBadge`. The icon is
`dev.monarchui.foundation.icon.MonarchIcon`.

Documentation cannot show code that does not compile: every example in an
inventory file is compiled into the unit tests and composed in the four
themes by `InventoryExamplesTest`, and every Kotlin block in this file is
checked against compiled source by `ReadmeExamplesTest`.

### Images and icons

Monarch ships no image loader and no icon set. A component that shows a
picture takes a `Painter?` loaded by the app and shows a placeholder while it
is `null`. A component that shows an icon takes it from the caller as an
`ImageVector`, a `Painter` or a composable slot.

### Time zones

A component parameter that takes a time zone is the IANA identifier as a
`String?`; `null` means the device's zone, read each time. A `String` keeps
the parameter stable and immutable for Compose. A value that is stored or sent
between processes, such as `MonarchBusinessHoursValue.timeZone` or the slot
picker's data, is the same IANA `String`, as on the web and on iOS.

## Accessibility

Each component:

- has a touch target of at least 48dp, also when the visible control is
  smaller (a small button is 36dp high in a 48dp target);
- exposes its role, state and label to TalkBack;
- uses sp for text and grows with the font size setting;
- uses start and end, so it mirrors in right-to-left layouts;
- takes its colours from the roles of the active theme.

Helpers for custom elements: `Modifier.monarchMinimumTouchTarget()`,
`Modifier.monarchFocusRing(shape)` and `isReducedMotionEnabled()`.

These behaviours are checked by tests on the JVM. They have not been checked
with TalkBack on a device in this iteration.

Built-in strings are resources with the prefix `monarch_` in
`monarch-compose/src/main/res/values/strings.xml`. An app can translate them
by declaring the same names, and each can be replaced per call by a parameter.

## Commands

Run from `platforms/android`.

| Command                                                                                                     | What it does                                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `./gradlew componentCheck -Pcomponent=MonarchBadge`                                                         | The fast loop for one component (type name, title or id): its tests, fixtures, examples, previews, detekt on its files, and the catalogue compiles. |
| `./gradlew verifyLocal`                                                                                     | Everything to pass before handing a component over: generation, detekt, lint, all unit tests, the catalogue builds. Skips the API check.            |
| `./gradlew mergeCheck`                                                                                      | For the merged tree: regenerates `components.json` and the API dumps, reports parity with `../parity.json`, then runs `verifyMonarch`.              |
| `./gradlew verifyMonarch`                                                                                   | The complete gate: `components.json` is current, tests, API check, detekt, lint, debug and release catalogue builds, local publish.                 |
| `./gradlew generateInventory`                                                                               | Validates `inventory/*.json` and the conventions and writes `components.json`.                                                                      |
| `./gradlew parityReport`                                                                                    | Compares the inventory with `../parity.json`.                                                                                                       |
| `./gradlew :monarch-tokens:test`                                                                            | Unit tests of the tokens.                                                                                                                           |
| `./gradlew :monarch-compose:testDebugUnitTest`                                                              | Unit and Compose UI tests on the JVM (Robolectric). No device needed.                                                                               |
| `./gradlew :monarch-compose:testDebugUnitTest --tests "dev.monarchui.components.actions.MonarchButtonTest"` | One test class.                                                                                                                                     |
| `./gradlew :monarch-compose:testDebugUnitTest --tests "*MonarchButtonTest.aLoading*"`                       | One test method, by pattern.                                                                                                                        |
| `./gradlew apiCheck`                                                                                        | Compares the public API with `monarch-tokens/api/` and `monarch-compose/api/`.                                                                      |
| `./gradlew apiDump`                                                                                         | Rewrites the API dumps after an intended API change. Commit the result.                                                                             |
| `./gradlew detekt`                                                                                          | Static analysis with `config/detekt/detekt.yml`.                                                                                                    |
| `./gradlew :monarch-compose:lintDebug :sample:lintDebug`                                                    | Android lint. Warnings are errors.                                                                                                                  |
| `./gradlew :sample:assembleDebug`                                                                           | Builds the catalogue app (`sample/build/outputs/apk/debug/`).                                                                                       |
| `./gradlew :sample:installDebug`                                                                            | Installs the catalogue on a connected device or emulator.                                                                                           |
| `./gradlew publishAllPublicationsToLocalRepository`                                                         | Publishes both libraries to `build/repo`.                                                                                                           |

## Updating versions

Every version is in `gradle/libs.versions.toml` and nowhere else. The
`monarch` entry is the exception to editing it by hand: it is the
`@rookcom/monarch-react` version.

| To change                                                 | Edit in `[versions]`                | Also                                                                                                                               |
| --------------------------------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Monarch for Android version                               | not by hand                         | Written from `packages/react/package.json` by the version-sync script. Add the version to `CHANGELOG.md`.                          |
| Kotlin, and the Compose compiler plugin                   | `kotlin`                            | They share one version.                                                                                                            |
| Android Gradle plugin                                     | `agp`                               | Check the Gradle and JDK versions it needs.                                                                                        |
| Compose and Material 3                                    | `composeBom`                        | Run `apiDump` only if the public API changed.                                                                                      |
| compileSdk, targetSdk, minSdk                             | `compileSdk`, `targetSdk`, `minSdk` | The platform must be installed in the Android SDK.                                                                                 |
| JDK toolchain, bytecode target                            | `jdk`, `jvmTarget`                  |                                                                                                                                    |
| detekt, Robolectric, JUnit, Espresso, Lifecycle, Activity | the key of the same name            |                                                                                                                                    |
| Gradle                                                    | not in the catalog                  | `./gradlew wrapper --gradle-version <version>`, then update `distributionSha256Sum` in `gradle/wrapper/gradle-wrapper.properties`. |

After any version change run `./gradlew verifyMonarch`.

## Public API policy

- The public API is explicit (`explicitApi()`): everything not marked
  `public` is internal.
- It is recorded in `monarch-tokens/api/` and `monarch-compose/api/` and
  checked on every `verifyMonarch`. A change to those files is an API change
  and is reviewed as one. The dumps are regenerated once, on the merged tree
  (`mergeCheck`), not by each author.
- `dev.monarchui.internal` is not public API.
- `@ExperimentalMonarchApi` marks API that can change without a deprecation
  period. Using it requires an opt-in. The experimental components are the
  inventory entries with `"status": "experimental"`.
- A deprecated API is removed no sooner than 90 days and two patch releases
  after the release that deprecates it
  ([native API stability](../../docs/governance/native-api-stability.md#deprecation-policy)).
