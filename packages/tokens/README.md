# @rookcom/monarch-tokens

Framework-independent Rook design tokens. Exports: `./css` (all themes),
`./css/base`, `./css/compat` (legacy shadcn names, deprecated),
`./css/products/<id>`, `./tailwind` (Tailwind 3 preset), `./appearance`
(pre-paint boot script), `./tokens.json`, `./contrast-report.json`, and a TS
API (`themes`, `resolveTheme`, `contrast`, `brand`, `products`).
Docs: ../../docs/guides/theming.md
